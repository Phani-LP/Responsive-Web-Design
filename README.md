# Responsive Web Design Projects

This repository contains projects developed as part of the **Responsive Web Design** course by [freeCodeCamp](https://www.freecodecamp.org/learn/2022/responsive-web-design/). These projects demonstrate various aspects of responsive web design, including HTML and CSS techniques.

## Projects

### 1. Cat Photo App
- **File**: [Cat photo app.html](Cat%20photo%20app.html)
- **Description**: A simple webpage showcasing cat photos, lists, and a form for cat-related preferences.

### 2. Building a Nutrition Label
- **Files**: 
  - [index.html](Building%20a%20Nutrition%20Label/index.html)
  - [styles.css](Building%20a%20Nutrition%20Label/styles.css)
- **Description**: A webpage that replicates a nutrition label using HTML and CSS.

### 3. Cafe Menu App
- **Files**: 
  - [index.html](Cafe%20Menu%20App/index.html)
  - [styles.css](Cafe%20Menu%20App/styles.css)
- **Description**: A responsive cafe menu displaying coffee and dessert options with prices.

### 4. Color Markers
- **Files**: 
  - [index.html](Color%20Markers/index.html)
  - [styles.css](Color%20Markers/styles.css)
- **Description**: A webpage showcasing colored markers using CSS styling.

### 5. Registration Form
- **Files**: 
  - [index.html](Registration%20Form/index.html)
  - [styles.css](Registration%20Form/styles.css)
- **Description**: A responsive registration form with various input fields and validation.

### 6. Survey Form Certification Project
- **Files**: 
  - [main.html](Survay%20Form%20Certification%20Project/main.html)
  - [styles.css](Survay%20Form%20Certification%20Project/styles.css)
- **Description**: A survey form created as part of the freeCodeCamp certification project.
